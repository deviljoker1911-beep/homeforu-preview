# HomeforU app preview

A click-through preview of the redesigned HomeforU app ("Acid Night"). It is a static build: it runs entirely in your browser from a snapshot of
sample listings, and nothing is sent to or stored on a server. Sign-in, enquiries, bookings and payments are simulated.

Open it on a phone (or a narrow browser window): https://deviljoker1911-beep.github.io/homeforu-preview/

The listings, agencies and photos are demo content. This page is a demo and is not indexed by search engines.
